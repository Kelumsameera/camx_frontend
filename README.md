# CAMX Frontend – Earlier Repository

Next.js + React/TypeScript frontend for CAMX e-commerce functionality.

## Stack
Next.js 16, React 19, TypeScript, Tailwind CSS, Axios, React Hot Toast and React Icons.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` and `npm run lint` before deployment.

## Repository relationship

## Deployment checklist

Configure your backend URL, authentication and other environment settings securely. Verify product, cart, ordering and admin workflows with the matching backend version. No build or integration tests were performed as part of this README update.
